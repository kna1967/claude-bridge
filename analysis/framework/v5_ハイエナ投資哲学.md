# v5 ハイエナ投資哲学

## 基本理念

**「個人投資家の構造的優位性を活用し、機関投資家の感情売りを規律ある分析で利益に変える」**

---

## なぜハイエナか

ライオンや狼ではなく、ハイエナをモチーフとした理由:

### ハイエナ的特性
1. **自分で狩らない**(獲物=銘柄を見つけない、市場の歪みを待つ)
2. **大型動物の食べ残しを狙う**(機関投資家が見落とした or 過剰に売られた銘柄)
3. **強い者に挑まない**(短期勝負・デイトレ等しない)
4. **集団行動**(分散投資、過剰集中を避ける)
5. **死肉から栄養**(下落銘柄の中の優良を拾う)
6. **無駄な争いを避ける**(熱狂相場で買わない、冷静に待つ)
7. **知的、組織的**(13軸 + 軸⑭の体系化)

### 反対の生き方(避けるべき)
- ✗ ライオン的: 自分で狩る(短期勝負)
- ✗ チーター的: スピード勝負(デイトレ)
- ✗ 群れの先頭(モメンタム追随)

---

## 個人投資家の構造的優位性

### 機関投資家との4つの違い

| 項目 | 機関投資家 | 個人投資家 |
|---|---|---|
| **時間軸** | 四半期/年次評価 | **5年、10年、永久保有可能** |
| **規模制約** | $1B以下に投資不可 | **小型株を自由に取引** |
| **説明責任** | 顧客への説明、追随圧力 | **逆張り、長期保有を自由実行** |
| **流動性影響** | 大量買いで価格を動かす | **静かに有利な価格で取得** |

### この優位性を最大化するのがハイエナ投資

---

## ハイエナ投資の5原則

### 原則1: 待つ忍耐
- 機会がない時は何もしない
- 「取引したい衝動」を抑える
- 月1-3回以下の取引が理想

### 原則2: 規律あるエントリー
- 13軸での精査(最低2-3軸)
- 打診買い → 第2段階 → 本格買い
- 一気買いの誘惑を排除

### 原則3: 規律あるエグジット
- 軸⑭ 利確規律システムで機械的執行
- 段階的利確(+20%、+40%、+70%、+150%)
- 損切り絶対遵守(-15%等)

### 原則4: 認知バイアス排除
- ストーリー先行警戒
- 確証バイアス排除
- バズワード警戒
- 判断疲れ認識

### 原則5: 継続的改良
- v5 → v6 → v7 と進化
- 失敗事例の体系化
- 自己評価メトリクス

---

## v5.3 で加わった2つの新視点 ⭐NEW(v5.3)

ハイエナ投資情報局のオプトラン分析を契機に、「業績・需給・バリュエーション」の財務軸だけでは捉えきれない**構造的視点**を加えた。

### 視点A: 実態としての企業国籍判定

「上場している国 = その国の企業」とは限らない。資本構造、経営陣、事業実態、法的環境の4面から **「実質的な国籍」** を判定する。

- 日本上場でも実態が中国寄りなら、米中対立リスク・規制リスクが直撃する
- 「日本企業の皮を被った中華企業」は、為替・地政学・倫理の3面で純粋日本企業と全く異なる扱いが必要
- 詳細は [[v5_13軸ハイエナ流分析テンプレート]] 軸⑦G を参照

### 視点B: 倫理的・国家観評価(デュアルユース倫理)

**「儲かるか」だけでなく、「日本という国にとって、また人類社会にとって、この企業は何をしているか」を問う。**

ハイエナは自然界で「死肉を分解する役割」を担う社会的存在であり、無原則に獲物を食い荒らす盗賊ではない。

- デュアルユース技術(半導体・光学・先端材料・AI・通信)は軍民両用で、用途次第で日本の安全保障に直結
- 投資先の選別を通じて、結果として日本の経済安全保障・社会の健全性に寄与する
- 倫理判定が「除外」となる銘柄には、いかにファンダが強くてもエントリーしない
- 詳細は [[v5_13軸ハイエナ流分析テンプレート]] 軸⑪E を参照

### 5原則との関係

新視点は「5原則を否定するもの」ではなく **「5原則の規律を、財務軸の外まで拡張するもの」** である。

| 5原則 | v5.3 での拡張 |
|---|---|
| 原則1 待つ忍耐 | カントリーリスク高銘柄は「永久に待つ」(=投資しない)ことも選択肢 |
| 原則2 規律あるエントリー | 国籍判定・倫理判定をエントリー前必須チェックに追加 |
| 原則3 規律あるエグジット | 倫理判定が悪化したら利益が出ていても撤退 |
| 原則4 認知バイアス排除 | 「日本企業だから安心」というバイアスを排除 |
| 原則5 継続的改良 | v5.3 の視点を実銘柄で運用しながら磨く |

## 「最強」ではなく「最適解の一つ」

### 健全な認識

```
✓ ハイエナ投資は優れた戦略の「一つ」
✓ 規律を守れる個人投資家には特に有効
✓ 継続的改良が前提
✓ 他戦略にも学べる点がある
✗ 「最強」と思った瞬間、進化が止まる
```

### 他戦略との比較

| 戦略 | 期待リターン | リスク | 向いている人 |
|---|---|---|---|
| **インデックス投資** | 年6-8% | 中 | 時間がない人、シンプル志向 |
| **配当再投資** | 年5-7% | 中 | 安定志向、長期 |
| **バリュー(ハイエナ)** | 年7-10% | 中-高 | 規律ある人、分析好き |
| **グロース** | 年8-15% | 高 | 成長企業見極め力 |
| **モメンタム** | 年10-20%(変動大) | 極高 | 技術分析得意な人 |
| **デイトレ** | 年-5〜+50% | 極高 | プロ志向、専業 |

→ ハイエナ投資は**「規律ある個人」の最適解**

## ハイエナ投資が機能する5条件

### 絶対条件

1. **v5 を毎回実践**(例外なし)
2. **取引頻度を抑える**(月1-3回)
3. **認知バイアスチェック習慣化**
4. **損切り・利確を機械的執行**
5. **学習を継続**(失敗からの教訓蓄積)

### これらを満たせない場合

→ インデックス投資の方が優れている可能性が高い

---

## 失敗パターンの認識

### よくある失敗

#### パターン1: ハイエナのつもりがライオンになる
- 「これは絶対上がる」と確信して大量買い
- v5を適用せずに感情で判断
- 過剰集中を作る

#### パターン2: 待てずに早く食べる
- 機会がないのに無理矢理銘柄を探す
- 不適切な時期にエントリー
- 高値掴み

#### パターン3: 食べ過ぎる
- 利確タイミングを逃す
- 「もっと取れるはず」とFOMOに支配
- ピーク後の下落で利益消失

#### パターン4: 食べた獲物を離せない
- 取得価格に縛られる
- 損切りを延期
- ファンダ悪化を見て見ぬふり

### 失敗の共通原因

→ **規律の崩壊**(感情、疲労、衝動)
→ v5 軸⑭(利確規律)と認知バイアスチェックで対抗

定期的(月次/四半期)に自己評価:

| 指標 | 目標 | 測定方法 |

| 取引頻度 | 月3回以下 | 取引履歴カウント |
| v5 13軸適用率 | 90%以上 | 分析ノート作成率 |
| 損切り機械的執行率 | 95%以上 | 損切り発動 vs 実行 |
| 利確機械的執行率 | 95%以上 | 同上 |
| 認知バイアス検出時の判断保留 | 100% | 取引日誌記録 |
| 1年トータルリターン | 市場平均+α | パフォーマンス記録 |
