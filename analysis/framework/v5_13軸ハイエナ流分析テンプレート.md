# v5 13軸ハイエナ流分析テンプレート

> 個人投資家が「機関投資家の見落とし」と「市場の感情売り」を規律ある分析で利益に変えるためのフレームワーク

## 使い方

1. 銘柄ごとにこのテンプレを複製
2. ファイル名: `[Ticker]_[銘柄名]_[YYYY-MM-DD]_v5フル分析.md`
3. 全15軸を可能な限り埋める(全部できなくても可、最低5軸)
4. **末尾「総合結論・ハイエナ判定」を必ず記入**(v5.3 から必須)
5. 1ヶ月後・3ヶ月後に振り返って更新

### v5.3 の必須軸(海外進出・新規領域投資・国家戦略との関連が疑われる銘柄)

以下のいずれかに該当する銘柄では、**軸⑦G/H、軸⑪E、総合結論セクション** を必ず埋める:

- 海外売上比率が30%以上、または特定国(中国・米国等)依存が顕著
- 新規領域への巨額CAPEX・第二次創業を進めている
- デュアルユース技術(防衛・先端材料・通信・AI半導体など)を扱う
- 「日本企業」と称しつつ実態が他国寄りの可能性がある

### ステップ5: 事業ポートフォリオ改革の検出 ⭐NEW(v5.2)

### ステップ6: 一時的費用の精密分離 ⭐NEW(v5.3)

**「表面の利益率」と「実力の利益率」を分けて見る** — 棚卸資産評価損、貸倒引当金、持分法投資除外、減損損失など、本業の継続性とは無関係な費用を分離し、**実力ベースの粗利率/営業利益率**を再計算する。

#### A. 分離すべき主な一時的費用

| 費用項目 | 性質 | 分離基準 |
|---|---|---|
| 棚卸資産評価損(在庫評価減) | 一過性(価格下落・陳腐化) | 過去5年で同種費用が頻発していなければ控除 |
| 貸倒引当金繰入額 | 取引先信用悪化 | 巨額または特定先依存ならノイズ扱い |
| 持分法投資の除外/減損 | 関連会社処理 | 連結除外・減損で本業構造に直結しなければ控除 |
| 減損損失(のれん・固定資産) | M&Aや事業計画のリセット | 通常、特別損失で表示。本業ROEに影響しない範囲で控除 |
| 訴訟・規制関連の和解金 | 一過性 | 反復性なしなら控除 |
| リストラ費用(早期退職・拠点閉鎖) | 改革コスト | 軸①ステップ5(改革進捗)と連動 |

#### B. 表面 vs 実力の比較計算

| 指標 | 表面値(GAAP) | 一時的費用 | 実力値 |
|---|---|---|---|
| 売上総利益率 | %  | (棚卸評価損 等の控除) | % |
| 営業利益率 | % | (リストラ・減損 等の控除) | % |
| 純利益率 | % | (税効果を含めて再計算) | % |

例(オプトラン型): 表面の粗利率が **33.8%** だが、棚卸資産評価損・持分法投資除外を控除した実力値は **37.6%**。表面の見かけより本業は強い。

#### C. 実力値の使い方

- 同業比較は **表面値ではなく実力値** で行う(ノイズ除去後の競争力比較)
- 来期計画の利益率予測は実力値の延長線で組む
- 表面値と実力値の差が **5%pt以上** ある場合は「会計ノイズが大きい銘柄」として軸③F(プロの罠)とも連動して評価

### ステップ7: 先行指標の追跡 ⭐NEW(v5.3)

**「実績(売上・利益)」だけでなく、その手前の先行指標を必ず確認する** — 受注高・受注残・ARR・Pipelineなどは、3〜12ヶ月先の業績を映し出す。先行指標の伸びは実績より早く市場に織り込まれる。

#### A. 業界別の先行指標一覧

| 業界 | 主要先行指標 | 補助指標 |
|---|---|---|
| **設備投資・重工業・装置** | 受注高、受注残高、Book-to-Bill比 | 設備稼働率、引合件数 |
| **半導体・電子部品** | 受注残、リードタイム、稼働率 | 顧客のCAPEX計画 |
| **SaaS・サブスク** | ARR、ACV、Net Dollar Retention(NDR) | 解約率、アップセル率 |
| **コンサル・SI** | Pipeline、提案中案件、リードタイム | 受注率、平均案件規模 |
| **製薬・バイオ** | パイプライン本数、開発フェーズ進捗 | FDA/PMDA申請数 |
| **小売・外食** | 既存店売上、客数、客単価 | 出店ペース、ECシェア |
| **金融・不動産** | 残高(預金・貸出・運用) | 信用コスト、新規取扱高 |
| **広告・人材** | 取扱高、求人案件数 | クライアント数、単価 |

#### B. 評価基準(★1〜5)

| 先行指標の前年比 | 評価 | 解釈 |
|---|---|---|
| +30%以上 | ★★★★★ | 強烈な追い風、業績先行 |
| +15〜30% | ★★★★ | 健全成長 |
| +5〜15% | ★★★ | 平常運転 |
| -5〜+5% | ★★ | 横ばい・要警戒 |
| -5%以下 | ★ | 業績先行の悪化シグナル |

#### C. 実績との時間差を読む

- 受注 → 売上計上: 装置で **6-18ヶ月**、SaaS ARRはほぼ即時
- 「受注好調 + 業績未反映」 = **ハイエナ機会**(株価未織り込み)
- 「業績好調 + 受注減速」 = **下方修正リスク**(警戒)

### H. アフターマーケット分析 ⭐NEW(v5.2)

**「売り切り型」ではなく「継続収益が積み上がるか」を見る** — ハードウェア売却後のスペアパーツ、保守、サブスク、消耗品など、本体販売後に発生する**粘着的な収益層**を定量化する。

#### H-1. アフターマーケット収益の定義

### I. ビジネスモデル転換期(第二次創業) ⭐NEW(v5.3)

**「既存事業の延長」ではなく「全く新しい収益柱の立ち上げ」を進めている銘柄を見抜く** — 巨額CAPEX、新工場、新事業の売上目標が中期計画に明示されている場合、企業は「第二次創業期」にある。リスクは大きいが、転換に成功すれば株価の地殻変動が起きる(軸①ステップ5の戦略レベル版)。

> 軸①ステップ5(ポートフォリオ改革)= **会計上の名目 vs 実質の換算**
> 軸②I(第二次創業) = **戦略レベルでの新事業立ち上げ判定**
> 両者は補完関係。連動して評価する。

#### I-1. 第二次創業の判定基準

3つ以上該当で「第二次創業期」と認定:

- [ ] 中期計画に **新規セグメントの売上目標** が明示されている
- [ ] 過去3年の累計CAPEX が **過去5年平均の2倍以上**
- [ ] 新工場・新研究所・新拠点の建設が進行中
- [ ] M&Aで取得した技術・人材を新事業に投入している
- [ ] 経営陣が「第二の柱」「次世代主力」を明確にメッセージ
- [ ] 受注・引合件数が新事業領域で立ち上がっている(軸①ステップ7と連動)

#### I-2. 巨額設備投資の判定

| 指標 | 値 | 評価 |
|---|---|---|
| 直近3年累計CAPEX | | |
| 過去5年平均CAPEX比 | 倍 | 2倍以上で「巨額」判定 |
| CAPEX / 営業CF比 | % | 100%超は外部資金依存 |
| 自己資本比率の推移 | | 急激な悪化があればレバレッジ警戒 |

#### I-3. 新事業の売上目標の妥当性

| 項目 | 値 |
|---|---|
| 中期計画期間 | 〜__年度 |
| 新事業の目標売上 | __億円 |
| 同社全社売上に対する比率 | % |
| 目標達成の前提条件 | (顧客獲得、認証取得、技術完成 等) |
| 競合・市場規模との整合性 | (TAM比でのシェア妥当性) |

#### I-4. 転換期のリスクとリターン

**リターン側:**
- 新事業がP/Lに乗ると、利益率と成長率が一段ジャンプ
- 株価評価がPER 15倍 → PER 25倍にリレーティングされる可能性
- 「成長企業」入りで機関投資家の組み入れ拡大

**リスク側:**
- CAPEX回収失敗 → 減損リスク(軸①ステップ6と連動)
- 既存事業のキャッシュ食い潰し
- 技術・市場の不確実性で計画未達

#### I-5. ハイエナの間合い

- 巨額投資の **発表時** = 株価が一時的に下落することが多い(短期P/Lへの懸念)
- 投資の **完了直後〜立ち上がり期** = 不確実性ピーク = ハイエナ機会
- 立ち上がりが顕在化すると織り込みが急速に進む

判定:
- [ ] 同業の **2倍以上** → 個人投機筋の集中(罠リスク高)

- [ ] **「来期売上減」**等のヘッドラインで急落したが、**Non-GAAP/調整後利益は伸びている**(NEC型)
- [ ] **大型増配・自社株買い発表**で急騰したが、**業績裏付けは弱い**(配当維持の苦肉の策の可能性)
- [ ] **政策テーマ(防衛・AI・脱炭素)**でテーマ買いが先行、業績との乖離が広がっている

#### F-3. アナリスト目標株価との乖離パターン

| 状態 | 解釈 |
|---|---|
| 現在価格 << 目標株価(乖離 >40%) | 機関は割安と判断、個人は逃げている = ハイエナ機会 |
| 現在価格 ≈ 目標株価 | 織り込み済み、特別な歪みなし |
| 現在価格 >> 目標株価 | 個人の熱狂に機関は冷めている = テーマ株化(罠) |
